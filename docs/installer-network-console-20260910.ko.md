# 인스톨러 NIC 선택 및 영문 콘솔 (2026-09-10)

## 구현

- 실제 유선 NIC를 감지하여 이름, 연결 상태, MAC과 함께 드롭다운에 표시한다.
- 처음에는 링크가 연결된 NIC를 우선 선택하며 사용자가 변경할 수 있다.
- 새로고침 시 선택을 유지한다. 선택한 장치가 사라지면 경고하고 직접 지정 값으로 보존한다.
- 고급 직접 지정에서 장치 이름이나 패턴을 입력할 수 있다. eth* 또는 en*로 일괄 고정하지 않는다.
- DHCP, 고정 IP, 오프라인 설치 및 자동/수동 DNS를 선택할 수 있다.
- 수동 DNS는 DHCP에도 적용하며 쉼표 구분 입력을 공백으로 정규화한다.
- 현재 연결 확인은 설치 환경의 링크, IPv4 주소, 기본 경로를 조회한다. 입력 중인 설정 적용이나 DNS/인터넷 통신 검사는 하지 않는다.
- 네트워크 설정은 선택한 장치 이름을 사용한다. MAC 고정이나 VM 복제 시 장치 재매핑은 구현하지 않았다.
- 기본 tty AI 콘솔의 안내/승인/오류 문구와 모델 응답 지침을 영문으로 변경했다. GUI 인스톨러는 한글을 유지한다.
- 기본 콘솔 서비스는 kmscon 없이 직접 실행한다. 기존 한글 입력 별칭과 JSON 필드 호환성은 유지한다.
- 명령 출력이나 사용자 파일명까지 영문으로 강제 변환하지 않는다. 명령 실행 전 승인 절차는 유지한다.

## 검증

- GTK 빌드: -Wall -Wextra -Werror 통과.
- GTK 위젯 테스트: NIC 탐색, 연결 NIC 우선 선택, 선택 유지, 직접 지정, 장치 제거, DNS 정규화, 고정 IP 필드, 오프라인 통과.
- Go: installer-tui, kiki-ai-console, internal/aiconsole 테스트 통과.
- Python: boot service 회귀 8개, bootiso 35개 통과.

## 반영 범위

소스 수정 및 로컬 GTK 바이너리 빌드까지 완료했다. 새 패키지/저장소/ISO 생성과
Hyper-V kiki-os-test 재설치 검증은 아직 수행하지 않았다. 실행 중인 VM은 변경하지 않았다.
이 기록은 이전 부팅 서비스 기록의 기본 콘솔 kmscon 사용 계획을 대체한다.
기존 ISO는 교체본 검증 전까지 유지한다.
