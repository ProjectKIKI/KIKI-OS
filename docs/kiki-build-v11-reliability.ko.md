# 자동 백업·실행 취소·검증 통합

2026-11-01 구현. v1.0 태그와 릴리즈 파일은 변경하지 않는다.

## 자동 백업과 복구 검사

`tools/ki2autobackup.py --config 비공개설정.json`은 Linux에서 백업과 새 임시 경로 복구를 함께 실행한다. 운영 상태 파일은 해시 명세와 대조하며, SQLite는 온라인 백업을 사용한다. 복구본 인증 DB에 무결성 검사를 실행하고 로그인 세션을 폐기한다. 운영 DB의 세션은 변경하지 않는다. 복구된 임시 데이터는 시험 종료 후 제거하지만 원본·백업 파일은 보존한다.

`deploy/backup/config.example.json`을 비공개 위치에 복사해 실제 경로를 지정한다. 대상 디렉터리는 입력 경로 밖에 둔다. systemd 사용자 유닛 예시는 `deploy/systemd/kiki-build-backup.service`와 `.timer`이며 소스 경로를 실제 설치 위치로 변경한다. 매일 한국시간 03:15부터 최대 5분을 분산해 실행한다. 실행 중 작업이 있으면 연기한다. 중복 실행은 잠금으로 거부하며, 보관 한도에 도달해도 기존 백업을 자동 삭제하지 않는다.

운영 서버는 데이터 볼륨 100GB 중 약 11GB만 남았고 보관소는 약 56GB다. 현재 자동 백업은 **부분 백업**으로 계정·설정·카탈로그·서명 관련 상태·도구 소스를 포함한다. 작업 디렉터리·바이너리/소스 보관 객체·Git 인증 헬퍼와 미러 등은 제외한다. 2GiB의 보관 한도를 적용한다. 전체 산출물 백업은 별도 저장소 경로가 필요하다. 이 부분 백업으로 빈 서버에 모든 ISO와 패키지를 복구할 수 있다고 표시하지 않는다. 전체 서버 기동 복구 시험도 별도다.

백업 도중 JSON·설정 변경뿐 아니라 파일 추가·제거·크기·수정 시각 변경을 감지하면 결과를 폐기한다. SQLite는 개별 DB의 일관된 온라인 스냅샷으로 취급한다. 서로 다른 서비스의 모든 DB를 같은 시점으로 동결하는 전역 트랜잭션 백업은 아니다.

운영에서 부분 백업·격리 복구를 두 차례 수행했다. 최종 기록은 파일 1,700개, 압축 크기 16,808,173바이트, SHA-256 `a564f9d8d2e6130231e3fb862ecdae75916c82d5cfb746578b891c6e9f5e2025`다. 인증 DB 무결성과 복구 세션 1개 폐기를 확인했으며 `full_restore_verified=false`로 기록했다. `/operations`에서 최근 결과와 백업 범위를 조회한다.

## 실행 중 빌드 취소

대기 작업은 즉시 취소한다. 실행 중 작업은 취소 요청을 기록하고, 빌드 단계별 전용 프로세스 그룹에 종료 신호를 전달한다. 정상 종료되지 않은 자식은 강제 종료한다. 상태가 확정될 때까지 재시도를 허용하지 않는다. 로그·고정 입력·이미 생성된 산출물은 삭제하지 않는다. 아직 실행하지 않은 단계는 건너뛴다. 소스 가져오기 등 빌드 단계 밖의 준비 작업은 다음 실행 단계에 도달할 때 취소가 반영될 수 있다. 의도적으로 새 세션으로 이탈하는 비협조적 프로세스를 추적하는 cgroup 취소는 이번 범위가 아니다.

운영 서버의 기본 검사 작업 `20261101-132216-8059`를 실행 중 취소했다. 상태 `cancelled`, 종료 코드 130과 입력·로그 보존을 확인했다. 별도 Linux 시험에서는 종료 신호를 무시하는 무출력 자식 프로세스까지 종료되고 후속 단계가 실행되지 않는 것을 확인했다.

## 릴리즈 검증 결과

`/releases/validation`과 `/api/releases/validation`은 업데이트·ISO 검증을 함께 조회한다. 운영에서 29개 기록을 조회했다. 업데이트의 경우 현재 후보 명세 파일 해시와 서명된 보고서를 다시 검사하며, 보고서의 후보·계획·nonce·설치 집합과 승인 당시 해시가 달라지면 미검증으로 표시한다. 기존 안정 채널 승격 절차는 유지한다.

GUI 항목은 기존 계약의 로그인 화면 검사다. 로그인한 사용자 세션 시험으로 확대 해석하지 않는다. ISO의 클라우드 설치 보고 상태는 상세 기록으로 연결하며, 대조되지 않은 증적을 통과로 승격하지 않는다. 전체 검증 계약의 자동 승격이나 새 ISO 설치 증적 등록기는 추가하지 않았다.

운영 화면의 오래된 임시 파일 크기 집계는 응답 시간을 제한한다. 전체 크기를 계산하지 못하면 일부 집계임을 표시한다. 파일을 정리하거나 VM·릴리즈를 삭제하지 않는다.

- 변경된 취소 계약을 반영한 FIFO·재시도·로그·HTTP 검사 9개 통과.

- 로컬 WSL 시작에 간헐적인 오류가 있어 최종 신규 검사는 운영과 같은 Linux 컨테이너의 격리 임시 경로에서도 확인했다.
