# 터미널랩 공통 디자인 적용

KIKI 빌드 웹의 로그인·빌드·패키지·로그·버전·릴리즈·ISO·사용자 관리 화면에
터미널랩 클라우드 콘솔의 화면 규칙을 적용한다. 빌드 작업자와 릴리즈 작업자는
유지하고 인증 컨테이너에서 공통 화면을 제공한다.

## 디자인 기준

- 실제 터미널랩 클라우드 콘솔과 `modern-ui.css`, 사이트 브랜드의 글꼴·심볼을 기준으로 한다.
- 남색 아이콘 바 64px, 밝은 메뉴 216px, 흰색 상단 바, 청회색 작업 영역으로 구성한다.
- 배경 `#f3f7fb`, 메뉴 배경 `#f3f6fa`, 아이콘 바 `#242966`, 선택·주요 버튼 `#2455dd`,
  본문 `#101828`, 보조 글자 `#667085`, 테두리 `#e2e8f0`을 사용한다.
- Pretendard 계열 글꼴 우선순위와 시스템 대체 글꼴을 사용한다. 외부 폰트·스크립트·CDN을
  새로 요청하지 않으며 기존 CSP를 유지한다.
- 공식 플랫 터미널 심볼을 사용한다. 운영 수치·진행 상태는 기존 서버 응답에서 가져오며
  디자인용 예시 수치를 화면에 추가하지 않는다.
- 800px 이하에서는 메뉴 버튼으로 왼쪽 메뉴를 열고 닫는다. Escape로 닫을 수 있고
  닫힌 메뉴는 키보드 탐색에서 제외한다. 넓은 표는 해당 영역 안에서 가로 스크롤한다.

## 구현 위치

| 파일 | 역할 |
|---|---|
| `tools/ki2ci_theme.py` | 공통 메뉴·상단 바·로그인 화면과 작업자 HTML의 외곽 구성 교체 |
| `tools/ki2ci_theme.css` | 색상·타이포그래피·표·폼·반응형 화면 규칙 |
| `tools/ki2ci_theme.js` | 작은 화면 메뉴와 표 스크롤 컨테이너 |
| `tools/ki2ci_auth.py` | 기존 인증 검사 후 공통 화면 적용, 고정 CSS·JS 경로 제공 |
| `tools/ki2users_views.py` | 사용자 관리 본문에 같은 화면 구성 사용 |

작업자의 기존 폼 주소·입력 이름·CSRF·요소 ID·이벤트 대상·실시간 로그·갱신 메타 정보는
보존한다. HTML 응답에만 디자인을 적용하고 JSON 및 패키지·ISO 다운로드는 변환하지 않는다.
로그인용 CSS·JS만 인증 없이 공개하며 계정·빌드 API·산출물에는 기존 인증을 요구한다.

## 배포와 검증

인증 이미지에 공통 디자인 파일 3개를 포함하고 기존 `auth/state` 볼륨으로 실행한다.
인증 DB나 비밀번호를 복제하거나 초기화하지 않는다. 기존 설치기·패키지·보관 ISO와
컴파일러·릴리즈 컨테이너를 변경하지 않는다. 프록시·포트·보안그룹도 변경하지 않는다.

기존 역할별 접근 검사와 세션 정책을 유지한다. 이전 사용자 관리 이미지 및 서비스 설정은
남겨 두고, 화면 문제로 복구할 때도 계정별 권한을 지원하는 이미지만 사용한다.

`test_ki2ci_theme.py`는 폼·입력값·로그·스크립트·페이지 갱신 보존과 사용자 권한별 메뉴를
검증한다. `test_ki2ci_auth.py`는 로그인 CSS·JS 공개 범위와 기존 인증·CSRF를 검증한다.
기존 릴리즈·버전·ISO 회귀 테스트와 실제 브라우저의 데스크톱·모바일 검증을 병행한다.
