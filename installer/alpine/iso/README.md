# KIKI Alpine ISO Build

The KIKI installer ISO is built with Alpine's `aports/scripts/mkimage.sh`.

The build includes:

- a custom `profile_kiki`
- the KIKI overlay tarball from `installer/dist/kiki-alpine-overlay.tar.gz`
- runtime packages required by `kiki-install`

## Container Build

From the repository root:

```bash
bash installer/scripts/build-alpine-iso.sh --runner podman --release v3.20
```

or:

```bash
bash installer/scripts/build-alpine-iso.sh --runner docker --release v3.20
```

The first run needs network access to build the Alpine builder image and clone
`aports`.

## Local Alpine Build

On an Alpine build host:

```bash
apk add alpine-sdk syslinux xorriso squashfs-tools mtools dosfstools grub grub-efi git python3 py3-yaml
git clone --branch v3.20 https://gitlab.alpinelinux.org/alpine/aports.git installer/dist/iso-work/aports
bash installer/scripts/build-alpine-iso.sh --runner local --aports-dir installer/dist/iso-work/aports
```

## Dry Run

Print the commands without running network or package operations:

```bash
bash installer/scripts/build-alpine-iso.sh --runner podman --dry-run
```

## Output

ISO output goes to:

```text
installer/dist/iso/
```

The exact file name is generated by Alpine `mkimage.sh`.
