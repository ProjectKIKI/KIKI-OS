# incident-ai 데스크톱 문맥 가져오기 후보 — 미완성·미검증

**상태: 사용자 요청으로 보류 중. 컴파일·테스트·서버 통합·배포 전이다. 운영에 사용하지 않는다.**

이 디렉터리는 KIKI-OS 저장소에 보관한 독립 Go 후보 모듈이다. 실제 incident-ai 서버에서
`Register`를 호출하지 않으며, GTK 송신부도 아직 구현하지 않았다.
현재 검증 완료된 GTK 앱은 문맥 복사·분석 화면 열기·수동 붙여넣기 방식을 유지한다.
후보 파일을 저장소에 포함하거나 푸시하는 것만으로 자동 연동이 활성화되지 않는다.

목표는 선택 서비스와 검토한 로그를 HTTPS POST로 가져와 질문란에 자동 표시하고,
사용자가 검토·승인한 뒤 기존 로그인·역할·CSRF 검증을 거쳐 분석 요청을 전송하는 것이다.
입력 표시와 분석 실행은 별도 단계이며 수신 핸들러가 분석 API를 자동 호출하지 않는다.

현재 코드는 계약과 UI 동작의 초안이다. `Origin: null` 허용은 신뢰된 앱 인증이 아니며,
기존 Enter 전송 핸들러·승인 우회 경로·로그인 전후 초안·POST 재전송·본문 로깅·요청 제한·
HTML 구조 변경·CSP 호환성·임시 송신 파일 보호와 정리 등을 검증해야 한다.
UI 승인 체크는 서버 권한 검증을 대체하지 않는다. 테스트 파일도 아직 실행하지 않았다.

서버 접속을 준비하고 작업 재개 지시를 받은 뒤 별도 후보에서 검증한다.
완료 기능, 후보 SHA, 접속 경로 구분, 구현 순서와 체크리스트는
[진행 상황·재개 기록](E:/dev/KIKI-OS/docs/kiki-operations-progress-and-resume-20261108.ko.md)을 따른다.
